📄 TextUtils – React Text Utility App

TextUtils is a simple and fast web application built using React, HTML, and CSS that allows users to perform various text operations such as converting text to uppercase, lowercase, copying text, and more.

🚀 Features
🔠 Convert text to UPPERCASE
🔡 Convert text to lowercase
✂️ Remove extra spaces
📋 Copy text to clipboard
🔄 Clear text instantly
📊 Word and character count
⏱️ Estimated reading time
🌙 Light/Dark mode 
🛠️ Tech Stack
React.js – Frontend framework
HTML5 – Structure
CSS3 – Styling
